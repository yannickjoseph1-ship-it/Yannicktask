# app-aqua — dossier projet Aqu.app

Espace de travail produit : tout ce qui n'est pas du code applicatif.

| Dossier / fichier | Contenu |
| --- | --- |
| `cahier-des-charges.md` | Le cahier des charges, mis à jour à chaque évolution |
| `charte-graphique.md` | Couleurs, typographie, logo, composants, ton |
| `assets/logo/` | Logo Aqu.app (webp, png, 256 px) |
| `assets/textures/` | Texture bleu marine du hero |
| `assets/icons/` | Icônes d'application (192, 512, Apple touch) |
| `docs/` | Documents de travail (forecast, comptes rendus, exports) |
| `mobile/` | Coque mobile Capacitor (projet Android généré, iOS à ajouter sur Mac) |

Le code vit dans `../server` et `../client` ; les assets utilisés par le site sont copiés dans `../client/public/brand/`.
